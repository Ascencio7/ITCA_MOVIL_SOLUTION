# ITCA MOVIL SOLUTION

Este proyecto es una landing page para el evento de innovación tecnológica **ITCA MOVIL SOLUTION**, diseñada para mostrar información del evento, la galería, videos, formularios interactivos y una calculadora de inscripción.

La página incluye:
- Presentación del evento con logotipo y banner principal
- Calculadora de costos de inscripción
- Formulario de registro de participantes
- Galería fotográfica del evento
- Sección de videos de la actividad
- Footer con información institucional y redes sociales

## Tecnologías utilizadas

- PHP
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- AJAX
- Visual Studio Code

## Objetivo

Desarrollar una interfaz moderna y dinámica para promocionar el evento ITCA MOVIL SOLUTION, permitiendo a los usuarios:
- consultar costos
- registrar su participación
- visualizar contenido multimedia del evento
- explorar la experiencia del evento de forma atractiva

## Estructura del proyecto

- `index.php` — página principal
- `estilos.css` — estilos personalizados del sitio
- `procesar_calculadora.php` — procesamiento de la calculadora
- `procesar_registro.php` — procesamiento del registro
- `images/` — imágenes del proyecto
- `videos/` — videos del evento

## ⚙️ Requisitos previos

- PHP 8.0 o superior
- Servidor local compatible con PHP
- Navegador web moderno

## Cómo ejecutar el proyecto

1. Abre la carpeta del proyecto en tu equipo.
2. Entra a la carpeta raíz.
3. Ejecuta un servidor local con PHP:

```bash
php -S localhost:8000
```

4. Abre en el navegador:

```bash
http://localhost:8000
```

## Funcionalidades principales

### Calculadora de costos
Permite ingresar el nombre, cantidad de talleres y tipo de participante para calcular el costo de inscripción.

### Registro de participantes
Recolecta información personal, académica y de interés del usuario.

### Galería y videos
Muestra momentos visuales clave del evento y material audiovisual para reforzar la identidad del evento.

### Interactividad
Incluye animaciones, hover en cards, filtros visuales y botones para limpiar formularios y resultados.
